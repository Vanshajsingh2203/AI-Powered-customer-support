# AI-Powered Customer Support and Ticket Resolver

An AI-powered customer support platform designed to intelligently classify support tickets, retrieve relevant information, and assist in generating context-aware responses using Large Language Models (LLMs) and Retrieval-Augmented Generation (RAG).

I want to build this project because it was difficult for me to understand the basic things and then implement it , that is why I want to do this . FastAPI functionalities have been done in this with database integration , and then frontend works with backend concurrently , then background tasks will be implemented as well , and then finally AI integration will be followed where we will be introducing topics like , RAG  Langchain , LangGraph and maybe Agentic AI

The Basic backend and frontend development has been done .
